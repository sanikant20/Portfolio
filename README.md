# Portfolio — Sanikant Kushwaha

Personal portfolio website built with vanilla HTML, CSS, and JavaScript.

## Tech Stack

- Vanilla HTML / CSS / JavaScript
- Google Fonts (Syne, DM Mono, Instrument Sans)
- Dynamic section loading via Fetch API
- CSS custom properties for theming (dark/light mode)
- Intersection Observer for scroll animations

## Setup

No build tools or dependencies required. Open `index.html` in a browser or serve locally:

```bash
npx serve .
```

## Features

- Dark/light theme toggle (persisted to localStorage)
- Responsive layout (mobile, tablet, desktop)
- Scroll-triggered fade-up animations
- Grid background with radial mask on hero
- Section-based architecture with dynamic loading
